Diagnostic trust contract

Evidence first. Inference second.

The skill is designed to make the difference between an observation, a calculation, a hypothesis, an assumption, and a missing fact obvious.

PROVENANCE

Show where the claim came from

Important findings should trace back to supplied evidence rather than appearing as unsupported certainty.

FRESHNESS

Old evidence is not current telemetry

Historical or unknown-age evidence lowers confidence instead of silently acting like a live reading.

CONFLICTS

Disagreement stays visible

If two files disagree about a miner, rack, timestamp, or state, the package should surface the conflict rather than pick one quietly.

COMMON CAUSE

Check shared failures first

Rack, subnet, switch, power, cooling, firmware, and timing patterns are considered before dozens of independent hardware failures are claimed.

CONFIDENCE

“I don't know yet” is valid

High, Medium, Low, and Insufficient Evidence are meaningful outcomes, not decoration.

NEXT CHECK

Reduce uncertainty safely

The next recommendation should be the least-work read-only observation that best separates competing explanations.

Hard boundary

A troubleshooting assistant, not a remote control.

The public package reasons over evidence supplied to the AI session. It does not add a miner-control backend or privileged remote-management path.

  • No reboot or reset execution
  • No pool/wallet changes
  • No firmware flashing
  • No voltage/frequency tuning
  • No PDU or breaker switching
  • No network reconfiguration
  • No arbitrary state-changing shell execution

FAQ

What this package is—and what it isn't.

Does it connect directly to a mining site?

No. v1.1.0 reasons over evidence supplied to the AI session and ships no hosted collection or mining-control backend.

Is the public demo evidence real?

No. The five release scenarios are synthetic. Private real-world validation material is not published here.

Does sponsorship influence diagnoses?

No. Public sponsorship funds public work. Commercial ASIC Intelligence development is a separate relationship. Diagnostic conclusions are expected to follow evidence either way.

Why connect this package to ASIC Intelligence?

The free package demonstrates the diagnostic philosophy on immediate evidence. ASIC Intelligence is the broader product direction for persistent operational intelligence; its proprietary implementation remains separate from this repository.
