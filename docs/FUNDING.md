# Funding and Sponsorship

The ASIC Intelligence Plugin/Skill Package is free and is intended to remain independently useful without sponsorship. Funding is split into two transparent paths so supporters know what they are supporting.

## Public project sponsorship

Public-project sponsorship supports work that can be shared back through this repository, including:

- miner and firmware compatibility research
- additional public evidence guides
- synthetic fleet-scale evaluation scenarios
- Codex, Claude, and portable Agent Skill packaging
- documentation and installation improvements
- public benchmark methodology
- controlled validation using evidence that can be safely shared
- safety and diagnostic-quality testing

Sponsorship **does not purchase** a preferred diagnostic conclusion, equipment-control capability, hidden confidence boost, privileged operational access, or access to private systems. Conclusions remain evidence-driven regardless of who funds the project.

The repository includes `.github/FUNDING.yml` for the maintainer account. The Sponsor button becomes useful only after the corresponding GitHub Sponsors profile is enrolled and active. No external payment destination is published here until it has been verified.

## ASIC Intelligence development partnerships

Separate from open-project sponsorship, companies may discuss commercial/private ASIC Intelligence development work. These are separate arrangements with separate scope and terms.

### Integration Sponsor

For miner firmware, APIs, monitoring tools, infrastructure products, repair systems, and other vendors that want better compatibility or evidence handling. Typical work could include documented format support, compatibility validation, sanitized test fixtures, and integration research.

### Founding Design Partner

For mining operators and hosting companies that want to help shape early ASIC Intelligence development around real operational problems. A design partnership may fund private product development, controlled evaluation, and direct product feedback under a separate agreement.

Early commercial pricing is intentionally not fixed in this public repository. Scope, confidentiality, support, data handling, and deliverables should be agreed explicitly before money or private operational data changes hands.

## Sponsor recognition

Recognition is optional. A supporter may be listed in [`SPONSORS.md`](../SPONSORS.md) by name/logo if both sides agree, or remain anonymous. Funding never grants control over safety rules or diagnostic conclusions.

## Start a conversation

Use the GitHub repository for initial contact without posting confidential site information. For private commercial discussions, establish a private channel before sharing credentials, production logs, network maps, customer information, or other sensitive evidence.
