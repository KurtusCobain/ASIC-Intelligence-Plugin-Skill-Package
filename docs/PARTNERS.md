# ASIC Intelligence Partnerships

> **Help build the intelligence layer for Bitcoin mining.**
>
> **Use it. Integrate it. Fund it.**

The public Plugin/Skill Package is the lowest-friction way to evaluate the diagnostic approach. The broader ASIC Intelligence product is being developed separately for mining operations that need persistent context, deeper operational correlation, and site-scale intelligence.

## Use it

Install the free public package, run it against sanitized or private evidence in your own AI session, and report diagnostic-quality issues using a sanitized reproducer whenever possible.

## Integrate it

Hardware, firmware, monitoring, pool, repair, networking, power, and infrastructure vendors can collaborate on public compatibility work. Good integration projects produce something concrete: documented evidence formats, validation fixtures, compatibility tests, or reproducible diagnostic cases.

## Fund it

There are two paths:

- **Public Sponsor** — supports open compatibility, documentation, demos, and testing.
- **Integration Sponsor / Founding Design Partner** — funds separate scoped ASIC Intelligence development or industry collaboration.

## What we will not trade for funding

Funding does not buy favorable diagnostic conclusions, unsafe equipment-control behavior, hidden access to user evidence, or publication of another operator's confidential information.

## Contact

Start through the repository with a non-confidential description of the opportunity. Do not put private credentials, wallets, production network diagrams, employee information, or customer-identifying data in a public issue.
